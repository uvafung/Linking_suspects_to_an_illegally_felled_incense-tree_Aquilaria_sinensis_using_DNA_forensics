### Genotype Data
 
This directory contains the genotype data for _Aquilaria sinensis_ (incense tree) samples used in this study. We used a subsample of range-side samples from Hong Kong as well as potential source trees and particulates taken from personal items.
 
#### Input files provided: <br />
angsd_test1.tped – PLINK transposed genotype file containing SNP genotype information. <br />
angsd_test1.tfam – PLINK sample information file corresponding to the .tped genotype data. <br />
 
#### LD-pruned datasets: <br />
The following binary PLINK files contain the final dataset after filtering (minor allele frequency ≥ 0.05, genotype call rate ≥ 0.30) and linkage disequilibrium (LD) pruning. These files were used for downstream population genetic and kinship analyses. <br />
 
#### All 45 samples: <br />
IT_angsd_test1_maf05_geno03.ldprune.bed <br />
IT_angsd_test1_maf05_geno03.ldprune.bim <br />
IT_angsd_test1_maf05_geno03.ldprune.fam <br />
 
#### 40 samples: <br />
IT_angsd_test1_keep.ldprune.bed <br />
IT_angsd_test1_keep.ldprune.bim <br />
IT_angsd_test1_keep.ldprune.fam <br />
 
#### Sample order of names: <br />
Sample_order_names.txt – contains three columns, the Original name, the ANGSD order number (ANGSD_order) and the name used in the paper (Paper_name) <br />
