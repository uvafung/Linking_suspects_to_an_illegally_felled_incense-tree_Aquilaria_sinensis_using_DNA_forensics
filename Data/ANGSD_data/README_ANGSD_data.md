### Genotype Data
 
This directory contains the genotype data for _Aquilaria sinensis_ (incense tree) samples used in this study. We used a subsample of range-side samples from Hong Kong as well as potential source trees and particulates taken from personal items.
 
Input files provided:
angsd_test1.tped – PLINK transposed genotype file containing SNP genotype information.
angsd_test1.tfam – PLINK sample information file corresponding to the .tped genotype data.
 
LD-pruned datasets:
The following binary PLINK files contain the final dataset after filtering (minor allele frequency ≥ 0.05, genotype call rate ≥ 0.30) and linkage disequilibrium (LD) pruning. These files were used for downstream population genetic and kinship analyses.
 
All 45 samples:
IT_angsd_test1_maf05_geno03.ldprune.bed
IT_angsd_test1_maf05_geno03.ldprune.bim
IT_angsd_test1_maf05_geno03.ldprune.fam
 
40 samples:
IT_angsd_test1_keep.ldprune.bed
IT_angsd_test1_keep.ldprune.bim
IT_angsd_test1_keep.ldprune.fam
 
Sample order of names:
Sample_order_names.txt – contains three columns, the Original name, the ANGSD order number (ANGSD_order) and the name used in the paper (Paper_name)
